# Model

* [Session](/model/session.md) - One conversation with a coding agent, as agnt sees it: provider observation joined with user metadata.
* [Session key](/model/session-key.md) - The permanent identity of a conversation, separate from the process running it.
* [Runtime state](/model/runtime-state.md) - What the provider says the session is doing now; observed, never set by the user.
* [Workflow state](/model/workflow-state.md) - The user's own classification of a session; only the user changes it.
* [Origin](/model/origin.md) - How agnt came to know about a session: started by agnt, discovered live, or found in history.
* [Link](/model/link.md) - A PR, issue, or other URL attached to a session, ranked by where it came from.
