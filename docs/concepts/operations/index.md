# Operations

* [Start](/operations/start.md) - Typing a task and pressing Enter begins a new session in the current directory, in whichever way the provider supports.
* [Attach and resume](/operations/attach-and-resume.md) - Handing the terminal to the official CLI for a live session (attach) or a saved conversation (resume), then taking it back.
* [Hide and delete](/operations/hide-and-delete.md) - Hiding removes a row from agnt's list only; deleting removes the session for good through the provider's CLI.
